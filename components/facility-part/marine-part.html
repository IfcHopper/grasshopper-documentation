Marine Part

Marine Part (Marine Part) · IfcHopper > Facility Part

Creates an IFC marine part (IfcMarinePart).

Inputs​

NameTypeAccessDescription
Name (N)TextitemPart name. Default: Hopper Marine Part.
Description (D)TextitemPart description.
Type (T)TextitemPredefined type: ABOVEWATERLINE, ANCHORAGE, APPROACHCHANNEL, BELOWWATERLINE, BERTHINGSTRUCTURE, CHAMBER, CILL_LEVEL, COPELEVEL, CORE, CREST, GATEHEAD, GUDINGSTRUCTURE, HIGHWATERLINE, LANDFIELD, LEEWARDSIDE, LOWWATERLINE, MANUFACTURING, NAVIGATIONALAREA, PROTECTION, SHIPTRANSFER, STORAGEAREA, VEHICLESERVICING, WATERFIELD, WEATHERSIDE. Other values are written as USERDEFINED with the value as object type.
Usage (U)TextitemHow the part divides the facility: NotDefined, Lateral, Longitudinal, Region, Vertical. Default: NotDefined.
Parts (FP)IFC Facility PartlistNested parts (IfcMarinePart or IfcFacilityPartCommon).
Spaces (Sp)IFC SpacelistSpaces in the part.
Elements (E)IFC ElementlistObjects contained in the part.
Property Sets (PS)IFC Property SetlistProperty and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept.
Classifications (Cl)IFC ClassificationlistClassification references (Classification component). References in the same system: the last one is kept.
Placement (Pl)IFC PlacementitemWorld placement plane. Empty: the placement of the parent.
GlobalId (Id)TextitemIFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids.

Outputs​

NameTypeAccessDescription
Marine Part (FP)IFC Facility PartitemIfcHopper facility part (IfcMarinePart).
