Modify Facility Part

Modify Facility Part (ModPart) · IfcHopper > Facility Part

Edits any IFC facility part. Unconnected inputs keep their value; the GlobalId is kept.

Inputs​

NameTypeAccessDescription
Part (FP) *IFC Facility PartitemIfcHopper facility part to edit.
Name (N)TextitemNew name. Unconnected: unchanged.
Description (D)TextitemNew description. Unconnected: unchanged.
Type (T)TextitemNew predefined type. Unconnected: unchanged.
Usage (U)TextitemNew usage: NotDefined, Lateral, Longitudinal, Region, Vertical. Unconnected: unchanged.
Parts (FP)IFC Facility PartlistNested parts. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged.
Spaces (Sp)IFC SpacelistSpaces. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged.
Elements (E)IFC ElementlistContained objects. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged.
Property Sets (PS)IFC Property SetlistProperty and quantity sets put in place of the sets with the same name, or added; a set without properties deletes the set with its name. Unconnected: unchanged.
Classifications (Cl)IFC ClassificationlistClassification references put in place of the references in the same system, or added; a reference without a code removes the references of its system. Unconnected: unchanged.
Placement (Pl)IFC PlacementitemNew world placement plane. Unconnected: unchanged.

* Required.

Outputs​

NameTypeAccessDescription
Part (FP)IFC Facility PartitemEdited IfcHopper facility part.
