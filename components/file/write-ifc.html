Write IFC

Write IFC (WriteIFC) · IfcHopper > File

Writes an IfcHopper model to an IFC file. The path is output even when Write is false.

Inputs​

NameTypeAccessDescription
Model (M)IFC ModelitemIfcHopper model to write.
Name (N)TextitemFile name. '.ifc' is appended when missing. Default: IfcHopperFile.ifc.
Directory (D)TextitemOutput directory. Defaults to the IfcHopper folder in the user folder. A relative path is taken from the folder of the saved definition.
Write (W)BooleanitemSet to true to write the file. Default: False.
Schema (S)TextitemIFC schema to write: IFC2X3, IFC4, IFC4X3_ADD2. Empty: IFC4X3_ADD2 for new models, the schema of the source file for models read from a file. What the schema does not support is downgraded or left out, with a warning.

Outputs​

NameTypeAccessDescription
Path (P)TextitemFull path of the IFC file.
