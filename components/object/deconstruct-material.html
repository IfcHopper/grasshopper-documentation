Deconstruct Material

Deconstruct Material (DeMaterial) · IfcHopper > Object

Deconstructs an IFC material or material set. Part outputs list the layers, constituents or profiles of a set in order; a single material is its own only part.

Inputs​

NameTypeAccessDescription
Material (Mat) *IFC MaterialitemIfcHopper material.

* Required.

Outputs​

NameTypeAccessDescription
Class (C)TextitemIFC class: IfcMaterial, IfcMaterialLayerSet, IfcMaterialConstituentSet (also IFC2X3 material lists) or IfcMaterialProfileSet.
Name (N)TextitemName of the material or set.
Description (D)TextitemDescription.
Category (Cat)TextitemCategory of a single material, e.g. concrete or steel.
Colour (Col)ColouritemSurface colour of the material, or of the first part with one; empty when not styled. Alpha holds the transparency.
Materials (M)IFC MateriallistMaterial of each part; empty items for parts without material.
Part Names (PN)TextlistName of each layer, constituent or profile.
Part Categories (PC)TextlistCategory of each layer, constituent or profile.
Thicknesses (T)NumberlistThickness of each layer in document units (layer sets only).
Fractions (F)NumberlistShare of each constituent from 0 to 1; empty items when not given (constituent sets only).
Property Sets (PS)IFC Property SetlistProperty sets of the material or set (IfcMaterialProperties).
