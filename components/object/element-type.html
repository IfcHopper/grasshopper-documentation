Element Type

Element Type (Type) · IfcHopper > Object

Creates an IFC element type (e.g. IfcWallType), shared by the objects placing it, like a block definition. Connect it to the Element Type input of objects.

Inputs​

NameTypeAccessDescription
Class (C)TextitemIFC type class (e.g. IfcWallType) or the element class it types (e.g. IfcWall). Default: IfcBuildingElementProxyType.
Name (N)TextitemType name. Empty: the name of the block, else Hopper Type (with a warning).
Description (D)TextitemType description.
Type (T)TextitemPredefined type of the class (e.g. SOLIDWALL for IfcWallType). Other values are written as USERDEFINED with the value as element type.
Geometry (G)Generic DatalistBody geometry in type coordinates, written as a representation map: meshes, Breps, extrusions, surfaces and SubDs (faceted), or a block definition or instance (the objects of its definition; nested blocks are flattened).
Colour (Col)ColouritemSurface colour of the geometry (IfcStyledItem); alpha sets the transparency. Empty: block objects keep their object colours.
Material (Mat)IFC MaterialitemMaterial of the type (IfcRelAssociatesMaterial), shown by its objects without one of their own.
Property Sets (PS)IFC Property SetlistProperty and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept.
Classifications (Cl)IFC ClassificationlistClassification references (Classification component). References in the same system: the last one is kept.
GlobalId (Id)TextitemIFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids. With a block, empty means the GlobalId of the block, so objects made from its instances share this type.
Tag (Tag)TextitemIdentifier, e.g. a mark or the id of the authoring tool (Tag).
Attribute Names (AN)TextlistAttributes of the class beyond those of the other inputs, e.g. OverallHeight and OperationType of IfcDoor; an error lists those of the class.
Attribute Values (AV)Generic DatalistOne value per attribute name: text, numbers (lengths, areas and volumes in document units), booleans or enumeration values.

Outputs​

NameTypeAccessDescription
Element Type (ET)IFC Element TypeitemIfcHopper element type.
