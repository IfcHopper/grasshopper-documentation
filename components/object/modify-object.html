Modify Object

Modify Object (ModObject) · IfcHopper > Object

Edits an IFC element. Unconnected inputs keep their value; the GlobalId and class are kept.

Inputs​

NameTypeAccessDescription
Object (O) *IFC ElementitemIfcHopper element to edit.
Name (N)TextitemNew name. Unconnected: unchanged.
Description (D)TextitemNew description. Unconnected: unchanged.
Type (T)TextitemNew predefined type of the class. Unconnected: unchanged.
Geometry (G)GeometrylistNew body geometry in world coordinates, faceted to meshes; replaces the body when written back. Unconnected: unchanged (moves with a new placement).
Colour (Col)ColouritemNew surface colour of all geometry; alpha sets the transparency. A changed colour replaces the body when written back. Unconnected: unchanged (new geometry has no colour).
Parts (P)IFC ElementlistElements this object is made of. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged.
Openings (Op)IFC ElementlistOpenings voiding the object. Connected: replaces the list (empty removes all openings). Unconnected: unchanged.
Material (Mat)IFC MaterialitemNew material of the object (a material, layer set or constituent set). An edited material read from the file changes for every element using it. Connected but empty: removes the material, so the object shows its type's. Unconnected: unchanged.
Property Sets (PS)IFC Property SetlistProperty and quantity sets put in place of the sets with the same name, or added; a set without properties deletes the set with its name. Unconnected: unchanged.
Classifications (Cl)IFC ClassificationlistClassification references put in place of the references in the same system, or added; a reference without a code removes the references of its system. Unconnected: unchanged.
Element Type (ET)IFC Element TypeitemNew type of the object (IfcRelDefinesByType). An instance of its type becomes an instance of the new type in the same place, like replacing a block; other objects keep their geometry. Connected but empty: removes the type (an instance keeps its geometry). Unconnected: unchanged.
Placement (Pl)IFC PlacementitemNew world placement plane. Unconnected: unchanged.
Tag (Tag)TextitemIdentifier, e.g. a mark or the id of the authoring tool (Tag). Connected but empty: removes the tag. Unconnected: unchanged.
Attribute Names (AN)TextlistAttributes of the class beyond those of the other inputs, e.g. OverallHeight and OperationType of IfcDoor; an error lists those of the class.
Attribute Values (AV)Generic DatalistOne value per attribute name: text, numbers (lengths, areas and volumes in document units), booleans or enumeration values. Empty items remove the attribute; others keep their value.

* Required.

Outputs​

NameTypeAccessDescription
Object (O)IFC ElementitemEdited IfcHopper element.
