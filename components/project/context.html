Context

Context (Context) · IfcHopper > Project

Creates an IFC representation context (IfcGeometricRepresentationContext) with subcontexts, e.g. Model with Body and Axis.

Inputs​

NameTypeAccessDescription
Type (T)TextitemContext type: Model (3D) or Plan (2D). Default: Model.
Identifiers (Id)TextlistSubcontext identifiers, e.g. Body, Axis, Box, FootPrint, Annotation.
Target Views (V)TextlistTarget view per identifier: ELEVATION_VIEW, GRAPH_VIEW, MODEL_VIEW, PLAN_VIEW, REFLECTED_PLAN_VIEW, SECTION_VIEW, SKETCH_VIEW, NOTDEFINED. The last value is repeated for the remaining identifiers.
Precision (P)NumberitemGeometric precision, in metres. Default: 0.00001.
True North (N)VectoritemTrue north direction in the XY plane. Empty means +Y.

Outputs​

NameTypeAccessDescription
Context (Cx)IFC ContextitemIfcHopper representation context.
