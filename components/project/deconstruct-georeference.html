Deconstruct Georeference

Deconstruct Georeference (DeGeoref) · IfcHopper > Project

Deconstructs an IFC georeference.

Inputs​

NameTypeAccessDescription
Georeference (Geo) *IFC GeoreferenceitemIfcHopper georeference.

* Required.

Outputs​

NameTypeAccessDescription
CRS (CRS)TextitemProjected CRS name.
Eastings (E)NumberitemMap eastings of the model origin, in metres.
Northings (N)NumberitemMap northings of the model origin, in metres.
Height (H)NumberitemOrthogonal height of the model origin, in metres.
X Axis (X)VectoritemDirection of the model X axis in map coordinates.
Scale (S)NumberitemMap distance per model distance.
Geodetic Datum (GD)TextitemGeodetic datum.
Vertical Datum (VD)TextitemVertical datum.
Description (D)TextitemCRS description.
Map Zone (Z)TextitemMap zone.
