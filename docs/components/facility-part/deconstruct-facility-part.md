**Deconstruct Facility Part** (DePart) · IfcHopper > Facility Part

Deconstructs any IFC facility part. Nested parts and elements are loaded on demand.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Part** (FP) \* | IFC Facility Part | item | IfcHopper facility part. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Name. |
| **Description** (D) | Text | item | Description. |
| **GlobalId** (Id) | Text | item | IFC GlobalId. Empty for objects not yet written. |
| **Class** (C) | Text | item | IFC class, e.g. IfcBridgePart. |
| **Type** (T) | Text | item | Predefined type, or the object type when user defined. |
| **Usage** (U) | Text | item | How the part divides the facility. |
| **Parts** (FP) | IFC Facility Part | list | Nested parts. |
| **Spaces** (Sp) | IFC Space | list | Spaces in the part. |
| **Elements** (E) | IFC Element | list | Elements contained in the part. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets. Sets of the type are included unless the object has its own set with the same name (From Type on Deconstruct Pset and Deconstruct Qto). |
| **Classifications** (Cl) | IFC Classification | list | Classification references. References of the type are included unless the object has its own in the same system (From Type on Deconstruct Classification). |
| **Placement** (Pl) | Plane | item | World placement plane in document units. Empty when unknown. |
