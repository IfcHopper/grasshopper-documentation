**Modify Storey** (ModStorey) · IfcHopper > Facility Part

Edits an IFC building storey. Unconnected inputs keep their value; the GlobalId is kept.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Storey** (St) \* | IFC Storey | item | IfcHopper building storey to edit. |
| **Name** (N) | Text | item | New name. Unconnected: unchanged. |
| **Description** (D) | Text | item | New description. Unconnected: unchanged. |
| **Elevation** (El) | Number | item | New elevation in document units; the storey and its contents move with it. Unconnected: unchanged. |
| **Spaces** (Sp) | IFC Space | list | Spaces. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Elements** (E) | IFC Element | list | Contained objects. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets put in place of the sets with the same name, or added; a set without properties deletes the set with its name. Unconnected: unchanged. |
| **Classifications** (Cl) | IFC Classification | list | Classification references put in place of the references in the same system, or added; a reference without a code removes the references of its system. Unconnected: unchanged. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Storey** (St) | IFC Storey | item | Edited IfcHopper building storey. |
