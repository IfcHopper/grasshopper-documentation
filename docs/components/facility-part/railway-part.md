**Railway Part** (Railway Part) · IfcHopper > Facility Part

Creates an IFC railway part (IfcRailwayPart).

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Part name. Default: `Hopper Railway Part`. |
| **Description** (D) | Text | item | Part description. |
| **Type** (T) | Text | item | Predefined type: ABOVETRACK, DILATIONTRACK, LINESIDE, LINESIDEPART, PLAINTRACK, SUBSTRUCTURE, TRACK, TRACKPART, TURNOUTTRACK. Other values are written as USERDEFINED with the value as object type. |
| **Usage** (U) | Text | item | How the part divides the facility: NotDefined, Lateral, Longitudinal, Region, Vertical. Default: `NotDefined`. |
| **Parts** (FP) | IFC Facility Part | list | Nested parts (IfcRailwayPart or IfcFacilityPartCommon). |
| **Spaces** (Sp) | IFC Space | list | Spaces in the part. |
| **Elements** (E) | IFC Element | list | Objects contained in the part. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept. |
| **Classifications** (Cl) | IFC Classification | list | Classification references (Classification component). References in the same system: the last one is kept. |
| **Placement** (Pl) | IFC Placement | item | World placement plane. Empty: the placement of the parent. |
| **GlobalId** (Id) | Text | item | IFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids. |
