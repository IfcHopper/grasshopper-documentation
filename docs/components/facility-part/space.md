**Space** (Space) · IfcHopper > Facility Part

Creates an IFC space (IfcSpace), e.g. a room. Connect it to a site, facility, storey, facility part or space.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Space name. Default: `Hopper Space`. |
| **Description** (D) | Text | item | Space description. |
| **Type** (T) | Text | item | Predefined type: BERTH, EXTERNAL, GFA, INTERNAL, PARKING, SPACE. Other values are written as USERDEFINED with the value as object type. |
| **Spaces** (Sp) | IFC Space | list | Nested (partial) spaces. |
| **Elements** (E) | IFC Element | list | Objects contained in the space. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept. |
| **Classifications** (Cl) | IFC Classification | list | Classification references (Classification component). References in the same system: the last one is kept. |
| **Placement** (Pl) | IFC Placement | item | World placement plane. Empty: the placement of the parent. |
| **GlobalId** (Id) | Text | item | IFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids. |

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Space** (Sp) | IFC Space | item | IfcHopper space. |
