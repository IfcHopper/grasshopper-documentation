**Read IFC Header** (Header) · IfcHopper > File

Reads the header of an IFC file and the project name.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Path** (P) \* | Text | item | Path of the IFC file. A relative path is taken from the folder of the saved definition. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Project** (Pr) | Text | item | Name of the IfcProject. |
| **Schema** (S) | Text | list | FILE_SCHEMA identifiers. |
| **Description** (D) | Text | list | FILE_DESCRIPTION description (view definitions). |
| **Implementation Level** (IL) | Text | item | FILE_DESCRIPTION implementation level. |
| **Name** (N) | Text | item | FILE_NAME name. |
| **Time Stamp** (T) | Text | item | FILE_NAME time stamp. |
| **Author** (A) | Text | list | FILE_NAME author. |
| **Organization** (O) | Text | list | FILE_NAME organization. |
| **Preprocessor** (PV) | Text | item | FILE_NAME preprocessor version. |
| **Originating System** (OS) | Text | item | FILE_NAME originating system. |
| **Authorization** (Au) | Text | item | FILE_NAME authorization. |
