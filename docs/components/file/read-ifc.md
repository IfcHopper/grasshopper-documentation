**Read IFC** (ReadIFC) · IfcHopper > File

Reads an IFC file into an IfcHopper model. Only the project is converted; deconstruct components load the rest on demand. Lengths are converted to Rhino units. Omitted products are reported by IFC class and count, including invalid abstract product instances. Large stored coordinates and local placements produce a warning; meshes retain double precision without relocating the model.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Path** (P) \* | Text | item | Path of the IFC file. A relative path is taken from the folder of the saved definition. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Model** (M) | IFC Model | item | IfcHopper model read from the file. |
