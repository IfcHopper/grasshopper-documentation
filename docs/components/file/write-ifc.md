**Write IFC** (WriteIFC) · IfcHopper > File

Writes an IfcHopper model to an IFC file. The path is output even when Write is false.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Model** (M) | IFC Model | item | IfcHopper model to write. |
| **Name** (N) | Text | item | File name. '.ifc' is appended when missing. Default: `IfcHopperFile.ifc`. |
| **Directory** (D) | Text | item | Output directory. Defaults to the IfcHopper folder in the user folder. A relative path is taken from the folder of the saved definition. |
| **Write** (W) | Boolean | item | Set to true to write the file. Default: `False`. |
| **Schema** (S) | Text | item | IFC schema to write: IFC2X3, IFC4, IFC4X3_ADD2. Empty: IFC4X3_ADD2 for new models, the schema of the source file for models read from a file. What the schema does not support is downgraded or left out, with a warning. |

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Path** (P) | Text | item | Full path of the IFC file. |
