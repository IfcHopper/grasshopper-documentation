**Constituent Set** (Constituents) · IfcHopper > Object

Creates an IFC material constituent set (IfcMaterialConstituentSet): named parts of an element and their materials, e.g. the frame and glazing of a window. Written as a material list without names and fractions in IFC2X3.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) \* | Text | item | Constituent set name. |
| **Description** (D) | Text | item | Constituent set description. |
| **Materials** (M) \* | IFC Material | list | Material of each constituent (single materials). |
| **Constituent Names** (CN) | Text | list | Name of each constituent, e.g. Frame, Glazing. |
| **Fractions** (F) | Number | list | Share of the element made of each constituent, from 0 to 1. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Constituent Set** (CS) | IFC Material | item | IfcHopper material constituent set. |
