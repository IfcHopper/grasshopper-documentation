**Deconstruct Classification** (DeClass) · IfcHopper > Object

Deconstructs a classification reference (IfcClassificationReference). References nested in other references give the system at the top.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Classification** (Cl) \* | IFC Classification | item | IfcHopper classification reference. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **System** (S) | Text | item | Classification system (IfcClassification name). |
| **Edition** (E) | Text | item | Edition of the system. |
| **Code** (C) | Text | item | Identifier of the item in the system. |
| **Name** (N) | Text | item | Name of the item. |
| **Location** (L) | Text | item | URI of the item. |
| **From Type** (FT) | Boolean | item | True when the reference is inherited from the object's type; such references are not written for the object. |
