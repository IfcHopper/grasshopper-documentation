**Deconstruct Material** (DeMaterial) · IfcHopper > Object

Deconstructs an IFC material or material set. Part outputs list the layers, constituents or profiles of a set in order; a single material is its own only part.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Material** (Mat) \* | IFC Material | item | IfcHopper material. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Class** (C) | Text | item | IFC class: IfcMaterial, IfcMaterialLayerSet, IfcMaterialConstituentSet (also IFC2X3 material lists) or IfcMaterialProfileSet. |
| **Name** (N) | Text | item | Name of the material or set. |
| **Description** (D) | Text | item | Description. |
| **Category** (Cat) | Text | item | Category of a single material, e.g. concrete or steel. |
| **Colour** (Col) | Colour | item | Surface colour of the material, or of the first part with one; empty when not styled. Alpha holds the transparency. |
| **Materials** (M) | IFC Material | list | Material of each part; empty items for parts without material. |
| **Part Names** (PN) | Text | list | Name of each layer, constituent or profile. |
| **Part Categories** (PC) | Text | list | Category of each layer, constituent or profile. |
| **Thicknesses** (T) | Number | list | Thickness of each layer in document units (layer sets only). |
| **Fractions** (F) | Number | list | Share of each constituent from 0 to 1; empty items when not given (constituent sets only). |
| **Property Sets** (PS) | IFC Property Set | list | Property sets of the material or set (IfcMaterialProperties). |
