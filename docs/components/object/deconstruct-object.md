**Deconstruct Object** (DeObject) · IfcHopper > Object

Deconstructs an IFC element.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Object** (O) \* | IFC Element | item | IfcHopper element. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Name. |
| **Description** (D) | Text | item | Description. |
| **GlobalId** (Id) | Text | item | IFC GlobalId. Empty for objects not yet written. |
| **Class** (C) | Text | item | IFC class, e.g. IfcWall. |
| **Type** (T) | Text | item | Predefined type, or the object type when user defined. |
| **Geometry** (G) | Mesh | list | Body geometry as meshes in world coordinates, with the openings subtracted (the body stored in the file is uncut). Read solids are faceted. |
| **Colour** (Col) | Colour | list | Surface colour of each mesh: its own style (IfcStyledItem), else the colour of the element's material; empty when neither is styled. Alpha holds the transparency. |
| **Parts** (P) | IFC Element | list | Elements this object is made of (IfcRelAggregates). |
| **Openings** (Op) | IFC Element | list | Openings and recesses voiding the element (IfcRelVoidsElement); deconstruct them as objects. |
| **Fills** (Fi) | IFC Element | list | For an opening: the elements filling it, e.g. doors and windows (IfcRelFillsElement). |
| **Material** (Mat) | IFC Material | item | Material of the element, or of its type when the element has none (IfcRelAssociatesMaterial). |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets. Sets of the type are included unless the object has its own set with the same name (From Type on Deconstruct Pset and Deconstruct Qto). |
| **Classifications** (Cl) | IFC Classification | list | Classification references. References of the type are included unless the object has its own in the same system (From Type on Deconstruct Classification). |
| **Element Type** (ET) | IFC Element Type | item | Type of the element (IfcRelDefinesByType). |
| **Placement** (Pl) | Plane | item | World placement plane in document units. Empty when unknown. |
| **Tag** (Tag) | Text | item | Identifier (Tag). |
| **Attribute Names** (AN) | Text | list | Set attributes of the class beyond the other outputs, e.g. OverallHeight of IfcDoor. |
| **Attribute Values** (AV) | Generic Data | list | Value of each attribute; lengths, areas and volumes in document units, enumerations as text. |
