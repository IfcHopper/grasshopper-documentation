**Deconstruct Pset** (DePset) · IfcHopper > Object

Deconstructs a property set (IfcPropertySet). Use Deconstruct Qto for quantity sets.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Pset** (PS) \* | IFC Property Set | item | IfcHopper property set. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Set name. |
| **Description** (D) | Text | item | Set description. |
| **From Type** (FT) | Boolean | item | True when the set is inherited from the object's type; such sets are not written. |
| **Names** (PN) | Text | list | Property names. |
| **Values** (V) | Generic Data | list | Values; lengths, areas and volumes in document units. Bounded numbers are domains; enumerated and list values are joined with "; ", tables as "defining: defined; …"; reference and complex properties are text. |
| **Types** (T) | Text | list | IFC value type of each property, e.g. IfcLabel. |
| **Kinds** (K) | Text | list | Property kind: Single, Enumerated, List, Bounded, Table, Reference or Complex. |
