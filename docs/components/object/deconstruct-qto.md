**Deconstruct Qto** (DeQto) · IfcHopper > Object

Deconstructs a quantity set (IfcElementQuantity). Use Deconstruct Pset for property sets.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Qto** (QS) \* | IFC Property Set | item | IfcHopper quantity set. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Set name. |
| **Description** (D) | Text | item | Set description. |
| **From Type** (FT) | Boolean | item | True when the set is inherited from the object's type; such sets are not written. |
| **Method** (M) | Text | item | Method of measurement, e.g. BaseQuantities. |
| **Names** (QN) | Text | list | Quantity names. |
| **Values** (V) | Number | list | Values. Lengths, areas and volumes in document units, weights in kg, times in s. |
| **Kinds** (K) | Text | list | Quantity kinds: Length, Area, Volume, Count, Weight, Time or Number. |
| **Formulas** (F) | Text | list | How each value was calculated; empty items when not given. |
