**Layer Set** (LayerSet) · IfcHopper > Object

Creates an IFC material layer set (IfcMaterialLayerSet), e.g. the build-up of a wall or slab, from the outside in.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) \* | Text | item | Layer set name, e.g. Cavity wall 300. |
| **Description** (D) | Text | item | Layer set description (IFC4 and later). |
| **Materials** (M) \* | IFC Material | list | Material of each layer (single materials). |
| **Thicknesses** (T) \* | Number | list | Thickness of each layer in document units. |
| **Layer Names** (LN) | Text | list | Name of each layer, e.g. Core, Insulation (IFC4 and later). |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Layer Set** (LS) | IFC Material | item | IfcHopper material layer set. |
