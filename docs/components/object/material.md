**Material** (Material) · IfcHopper > Object

Creates an IFC material (IfcMaterial). Connect it to objects, types or material sets; on write an existing material with the same name and values is reused.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) \* | Text | item | Material name, e.g. Concrete C30/37. |
| **Description** (D) | Text | item | Material description (IFC4 and later). |
| **Category** (Cat) | Text | item | Material category, e.g. concrete, steel, aluminium, block, brick, stone, wood, glass, gypsum, plastic, earth (IFC4 and later). |
| **Colour** (Col) | Colour | item | Surface colour of the material (IfcMaterialDefinitionRepresentation), shown on geometry without a colour of its own; alpha sets the transparency. |
| **Property Sets** (PS) | IFC Property Set | list | Property sets of the material (IfcMaterialProperties, IFC4 and later), e.g. Pset_MaterialCommon. Sets with the same name: the last one is kept. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Material** (Mat) | IFC Material | item | IfcHopper material. |
