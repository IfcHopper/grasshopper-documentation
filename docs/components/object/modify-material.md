**Modify Material** (ModMaterial) · IfcHopper > Object

Edits an IFC material or material set. Unconnected inputs keep their value. Written back to its file (through Apply Edits, or as the material of an object or type), the material changes for every element using it. To change the layers of a set, build a new set.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Material** (Mat) \* | IFC Material | item | IfcHopper material or material set to edit. |
| **Name** (N) | Text | item | New name. Unconnected: unchanged. |
| **Description** (D) | Text | item | New description (IFC4 and later). Unconnected: unchanged. |
| **Category** (Cat) | Text | item | New category of a single material (IFC4 and later). Unconnected: unchanged. |
| **Colour** (Col) | Colour | item | New surface colour of a single material; alpha sets the transparency. Unconnected: unchanged. |
| **Property Sets** (PS) | IFC Property Set | list | Property sets put in place of the material's sets with the same name, or added; a set without properties deletes the set with its name. Unconnected: unchanged. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Material** (Mat) | IFC Material | item | Edited IfcHopper material or material set. |
