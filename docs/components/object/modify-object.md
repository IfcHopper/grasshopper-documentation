**Modify Object** (ModObject) · IfcHopper > Object

Edits an IFC element. Unconnected inputs keep their value; the GlobalId and class are kept.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Object** (O) \* | IFC Element | item | IfcHopper element to edit. |
| **Name** (N) | Text | item | New name. Unconnected: unchanged. |
| **Description** (D) | Text | item | New description. Unconnected: unchanged. |
| **Type** (T) | Text | item | New predefined type of the class. Unconnected: unchanged. |
| **Geometry** (G) | Geometry | list | New body geometry in world coordinates, faceted to meshes; replaces the body when written back. Unconnected: unchanged (moves with a new placement). |
| **Colour** (Col) | Colour | item | New surface colour of all geometry; alpha sets the transparency. A changed colour replaces the body when written back. Unconnected: unchanged (new geometry has no colour). |
| **Parts** (P) | IFC Element | list | Elements this object is made of. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Openings** (Op) | IFC Element | list | Openings voiding the object. Connected: replaces the list (empty removes all openings). Unconnected: unchanged. |
| **Material** (Mat) | IFC Material | item | New material of the object (a material, layer set or constituent set). An edited material read from the file changes for every element using it. Connected but empty: removes the material, so the object shows its type's. Unconnected: unchanged. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets put in place of the sets with the same name, or added; a set without properties deletes the set with its name. Unconnected: unchanged. |
| **Classifications** (Cl) | IFC Classification | list | Classification references put in place of the references in the same system, or added; a reference without a code removes the references of its system. Unconnected: unchanged. |
| **Element Type** (ET) | IFC Element Type | item | New type of the object (IfcRelDefinesByType). An instance of its type becomes an instance of the new type in the same place, like replacing a block; other objects keep their geometry. Connected but empty: removes the type (an instance keeps its geometry). Unconnected: unchanged. |
| **Placement** (Pl) | IFC Placement | item | New world placement plane. Unconnected: unchanged. |
| **Tag** (Tag) | Text | item | Identifier, e.g. a mark or the id of the authoring tool (Tag). Connected but empty: removes the tag. Unconnected: unchanged. |
| **Attribute Names** (AN) | Text | list | Attributes of the class beyond those of the other inputs, e.g. OverallHeight and OperationType of IfcDoor; an error lists those of the class. |
| **Attribute Values** (AV) | Generic Data | list | One value per attribute name: text, numbers (lengths, areas and volumes in document units), booleans or enumeration values. Empty items remove the attribute; others keep their value. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Object** (O) | IFC Element | item | Edited IfcHopper element. |
