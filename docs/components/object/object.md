**Object** (Object) · IfcHopper > Object

Creates an IFC element (any instantiable IfcElement subclass, e.g. IfcWall). Connect it to a storey or facility part.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Class** (C) | Text | item | IFC element class, e.g. IfcWall, IfcSlab, IfcColumn, IfcBeam. Default: `IfcBuildingElementProxy`. |
| **Name** (N) | Text | item | Object name. Default: `Hopper Object`. |
| **Description** (D) | Text | item | Object description. |
| **Type** (T) | Text | item | Predefined type of the class (e.g. SOLIDWALL for IfcWall). Other values are written as USERDEFINED with the value as object type. |
| **Geometry** (G) | Geometry | list | Body geometry in world coordinates. Meshes are kept; Breps, extrusions, surfaces and SubDs are faceted; block instances are exploded. |
| **Colour** (Col) | Colour | item | Surface colour of the geometry (IfcStyledItem); alpha sets the transparency. |
| **Parts** (P) | IFC Element | list | Elements this object is made of (IfcRelAggregates), e.g. the members of an IfcElementAssembly. |
| **Openings** (Op) | IFC Element | list | Openings and recesses voiding the object (Opening component, IfcRelVoidsElement). Its geometry stays uncut in the file. |
| **Material** (Mat) | IFC Material | item | Material of the object (IfcRelAssociatesMaterial): a material, layer set or constituent set. Layer sets are written with a layer set usage (along the thickness of slabs, plates, coverings and roofs, across that of other elements). Empty: the material of its type. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept. |
| **Classifications** (Cl) | IFC Classification | list | Classification references (Classification component). References in the same system: the last one is kept. |
| **Element Type** (ET) | IFC Element Type | item | Type of the object (IfcRelDefinesByType). Without geometry the object is an instance of the type at its placement (IfcMappedItem); with geometry it keeps its own. A single block instance as geometry makes the object an instance of the block's type instead. Sets the class when Class is not given. |
| **Placement** (Pl) | IFC Placement | item | World placement plane. Empty: the placement of the parent. For a block instance, empty means the block's insertion plane. |
| **GlobalId** (Id) | Text | item | IFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids. |
| **Tag** (Tag) | Text | item | Identifier, e.g. a mark or the id of the authoring tool (Tag). |
| **Attribute Names** (AN) | Text | list | Attributes of the class beyond those of the other inputs, e.g. OverallHeight and OperationType of IfcDoor; an error lists those of the class. |
| **Attribute Values** (AV) | Generic Data | list | One value per attribute name: text, numbers (lengths, areas and volumes in document units), booleans or enumeration values. |

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Object** (O) | IFC Element | item | IfcHopper element. |
