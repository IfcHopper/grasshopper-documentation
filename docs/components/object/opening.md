**Opening** (Opening) · IfcHopper > Object

Creates an opening or recess (IfcOpeningElement). Connect it to the Openings input of Object or Modify Object: it voids that object, whose geometry stays uncut in the file. Doors and windows filling it must also be in a storey or space.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Opening name. Default: `Hopper Opening`. |
| **Description** (D) | Text | item | Opening description. |
| **Type** (T) | Text | item | OPENING (through the element) or RECESS (part of its thickness). Empty: not defined. |
| **Geometry** (G) \* | Geometry | list | Volume subtracted from the element, in world coordinates. Meshes are kept; Breps, extrusions, surfaces and SubDs are faceted. |
| **Fills** (Fi) | IFC Element | list | Elements filling the opening, e.g. doors and windows (IfcRelFillsElement). |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept. |
| **Classifications** (Cl) | IFC Classification | list | Classification references (Classification component). References in the same system: the last one is kept. |
| **Placement** (Pl) | IFC Placement | item | World placement plane. Empty: the placement of the element it voids. |
| **GlobalId** (Id) | Text | item | IFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Opening** (Op) | IFC Element | item | IfcHopper opening. |
