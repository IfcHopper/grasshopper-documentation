**Pset** (Pset) · IfcHopper > Object

Creates a property set (IfcPropertySet), e.g. Pset_WallCommon. Connect it to the Property Sets input of an object or spatial component.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) \* | Text | item | Set name, e.g. Pset_WallCommon. Standard IFC sets (Annex A) give the value types of their properties. |
| **Description** (D) | Text | item | Set description. |
| **Names** (PN) | Text | list | Property names. Empty: a set without properties, which deletes the set with its name on Modify components. |
| **Values** (V) | Generic Data | list | One value per name: booleans, integers, numbers or text; a domain for a bounded value; a Pset for a complex property. Text gives list ("a; b"), bounded ("lower .. upper") and table ("defining: defined; …") values. Lengths, areas and volumes in document units. Empty items: no value. |
| **Types** (T) | Text | list | IFC value types, e.g. IfcLabel, IfcBoolean, IfcLengthMeasure: one for all or one per name. Empty: the type of the standard set, else IfcBoolean, IfcInteger, IfcReal or IfcLabel from the value. |
| **Kinds** (K) | Text | list | Property kinds: Single, Enumerated, List, Bounded, Table or Complex; one for all or one per name. Empty: from the value (domain: Bounded, Pset: Complex), else the kind of the standard set, else Single. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Pset** (PS) | IFC Property Set | item | IfcHopper property set. |
