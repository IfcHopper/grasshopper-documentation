**Context** (Context) · IfcHopper > Project

Creates an IFC representation context (IfcGeometricRepresentationContext) with subcontexts, e.g. Model with Body and Axis.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Type** (T) | Text | item | Context type: Model (3D) or Plan (2D). Default: `Model`. |
| **Identifiers** (Id) | Text | list | Subcontext identifiers, e.g. Body, Axis, Box, FootPrint, Annotation. |
| **Target Views** (V) | Text | list | Target view per identifier: ELEVATION_VIEW, GRAPH_VIEW, MODEL_VIEW, PLAN_VIEW, REFLECTED_PLAN_VIEW, SECTION_VIEW, SKETCH_VIEW, NOTDEFINED. The last value is repeated for the remaining identifiers. |
| **Precision** (P) | Number | item | Geometric precision, in metres. Default: `0.00001`. |
| **True North** (N) | Vector | item | True north direction in the XY plane. Empty means +Y. |

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Context** (Cx) | IFC Context | item | IfcHopper representation context. |
