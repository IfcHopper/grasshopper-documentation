**Deconstruct Context** (DeContext) · IfcHopper > Project

Deconstructs an IFC representation context and its subcontexts.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Context** (Cx) \* | IFC Context | item | IfcHopper representation context. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Type** (T) | Text | item | Context type, e.g. Model or Plan. |
| **Dimension** (Dim) | Integer | item | Coordinate space dimension. |
| **Precision** (P) | Number | item | Geometric precision, in metres. |
| **True North** (N) | Vector | item | True north direction. Empty when not set (+Y). |
| **Identifiers** (Id) | Text | list | Subcontext identifiers. |
| **Target Views** (V) | Text | list | Target view of each subcontext. |
