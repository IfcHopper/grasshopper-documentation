**Georeference** (Georef) · IfcHopper > Project

Georeferences a project: maps the model origin and X axis to a projected CRS (IfcMapConversion, IfcProjectedCRS).

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **CRS** (CRS) \* | Text | item | Projected CRS name, e.g. EPSG:5110. |
| **Eastings** (E) | Number | item | Map eastings of the model origin, in metres. Default: `0`. |
| **Northings** (N) | Number | item | Map northings of the model origin, in metres. Default: `0`. |
| **Height** (H) | Number | item | Orthogonal height of the model origin, in metres. Default: `0`. |
| **X Axis** (X) | Vector | item | Direction of the model X axis in map coordinates (XY). Default: map east. Default: `{1,0,0}`. |
| **Scale** (S) | Number | item | Map distance per model distance (1 = no scaling). Default: `1`. |
| **Geodetic Datum** (GD) | Text | item | Geodetic datum, e.g. EUREF89. |
| **Vertical Datum** (VD) | Text | item | Vertical datum, e.g. NN2000. |
| **Description** (D) | Text | item | CRS description. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Georeference** (Geo) | IFC Georeference | item | IfcHopper georeference. |
