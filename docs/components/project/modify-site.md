**Modify Site** (ModSite) · IfcHopper > Project

Edits an IFC site. Unconnected inputs keep their value; the GlobalId is kept.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Site** (Si) \* | IFC Site | item | IfcHopper site to edit. |
| **Name** (N) | Text | item | New name. Unconnected: unchanged. |
| **Description** (D) | Text | item | New description. Unconnected: unchanged. |
| **Sites** (Si) | IFC Site | list | Nested sites. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Facilities** (F) | IFC Facility | list | Facilities. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Spaces** (Sp) | IFC Space | list | Spaces directly on the site. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Elements** (E) | IFC Element | list | Objects contained directly in the site. Connected: replaces the list; objects left out are deleted on write. Unconnected: unchanged. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets put in place of the sets with the same name, or added; a set without properties deletes the set with its name. Unconnected: unchanged. |
| **Classifications** (Cl) | IFC Classification | list | Classification references put in place of the references in the same system, or added; a reference without a code removes the references of its system. Unconnected: unchanged. |
| **Placement** (Pl) | IFC Placement | item | New world placement plane. Unconnected: unchanged. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Site** (Si) | IFC Site | item | Edited IfcHopper site. |
