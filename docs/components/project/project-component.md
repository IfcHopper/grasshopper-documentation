**Project** (Project) · IfcHopper > Project

Creates an IFC project (IfcProject) from sites, or from facilities placed directly under the project.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Name** (N) | Text | item | Project name. Default: `Hopper Project`. |
| **Description** (D) | Text | item | Project description. |
| **Sites** (Si) | IFC Site | list | Sites of the project. |
| **Facilities** (F) | IFC Facility | list | Facilities directly under the project, without a site. |
| **Contexts** (Cx) | IFC Context | list | Representation contexts. When empty, a default 3D Model context is written. |
| **Units** (U) | IFC Units | item | Units written to the file. Defaults to the Rhino document length unit with m2, m3 and radians. |
| **Georeference** (Geo) | IFC Georeference | item | Map conversion to a projected CRS. Empty: not georeferenced. |
| **Property Sets** (PS) | IFC Property Set | list | Property and quantity sets (Pset and Qto components). Sets with the same name: the last one is kept. |
| **Classifications** (Cl) | IFC Classification | list | Classification references (Classification component). References in the same system: the last one is kept. |
| **GlobalId** (Id) | Text | item | IFC GlobalId (22 characters) or GUID. Empty: a stable id derived from this component and the data branch/item, so writing again keeps the same ids. |

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Project** (Pr) | IFC Project | item | IfcHopper project. |
