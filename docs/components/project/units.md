**Units** (Units) · IfcHopper > Project

Defines the units written to an IFC file (IfcUnitAssignment). Lengths are converted from Rhino units on write.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Length** (L) | Text | item | Length unit: mm, cm, dm, m, km, in, ft. Defaults to the Rhino document units. |
| **Area** (A) | Text | item | Area unit: mm2, cm2, m2, in2, ft2. Default: `m2`. |
| **Volume** (V) | Text | item | Volume unit: mm3, cm3, m3, in3, ft3. Default: `m3`. |
| **Angle** (An) | Text | item | Plane angle unit: rad, deg. Default: `rad`. |

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Units** (U) | IFC Units | item | IfcHopper project units. |
