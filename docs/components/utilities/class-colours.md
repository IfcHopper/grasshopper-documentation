**Class Colours** (ClassCol) · IfcHopper > Utilities

One display colour per IFC object, based on its exact IFC class. Connect geometry and these Colours to native Custom Preview. Automatic colours stay stable across solves and reordering. Objects, IFC styles and default preview are unchanged.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Objects** (O) \* | Generic Data | tree | IFC objects to colour, including spatial objects and element types. Tree paths, order and empty positions are preserved; unsupported/null items produce empty colours. |
| **Classes** (C) | Text | list | Exact IFC classes to override, paired by index with Colours. Ignore case; no subclass expansion. * sets the colour for all other classes. Exact overrides win over *. Empty: automatic colours for every class. |
| **Colours** (Col) | Colour | list | One colour per override Class (including *); alpha/transparency is preserved. Classes with no exact or * override keep automatic colours. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Colours** (Col) | Colour | tree | One colour per input object, with the same tree paths and ordering. Empty entries mark unsupported/null objects. Wire to native Custom Preview's Material input. |
