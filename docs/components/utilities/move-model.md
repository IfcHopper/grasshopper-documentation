**Move Model** (MoveModel) · IfcHopper > Utilities

Translates all objects of a supported IfcHopper model in world X/Y, including parts, openings and fills. Geometry and placement origins move together. Rotations, Z and storey elevations stay unchanged. Keep Map Location compensates an existing georeference. Copies the object tree; geometry remains lazy. Does not write files.

## Inputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Model** (M) \* | IFC Model | item | IfcHopper model to translate. Source files with unsupported products or non-local placements are rejected rather than partly moved. |
| **X** (X) | Number | item | Signed world X translation in Rhino document units. Default: 0. Default: `0`. |
| **Y** (Y) | Number | item | Signed world Y translation in Rhino document units. Default: 0. Default: `0`. |
| **Keep Map Location** (K) | Boolean | item | True (default): adjust an existing georeference to preserve projected map positions. False: leave it unchanged, moving map positions too. No georeference: translate only; no CRS is inferred. Default: `True`. |

\* Required.

## Outputs

| Name | Type | Access | Description |
| --- | --- | --- | --- |
| **Model** (M) | IFC Model | item | Translated model copy. Connect to Find Objects to preview or Write IFC to save explicitly. Upstream model values are unchanged. |
